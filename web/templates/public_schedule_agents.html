Для ИИ и разработчиков

Обычный поиск

Расписание доступно в HTML страниц, без JavaScript и входа в Telegram.

Это не гарантирует, что любой чат автоматически найдёт сайт или включит веб-поиск. Для надёжного запроса можно передать ссылку на ККЭП и справочники.

Найти расписание

В каталоге перечислены группы, преподаватели, аудитории и даты архива. Поиск группы 103 возвращает несколько совпадений: выберите полное название, указанное пользователем, или попросите уточнить его.

Для группы 103-Д9-3ИНС: страница на 9 октября 2026 года, тот же день в JSON, расписание с 5 по 9 октября. Для преподавателя: Шульга Н.Н. на 9 октября.

В каждом дне проверяйте status. Ссылка на исходный документ — в source.url, номер редакции — в source.revision. Для даты без источника расписание не восстанавливайте по соседнему дню.

При ошибке веб-загрузчика попробуйте перейти из справочника групп к нужной группе и дате или открыть пример JSON выше. Успешный ответ сервера не гарантирует, что конкретный ИИ-инструмент прочитает страницу.

Структурированный API v2

Спецификация OpenAPI 3.1 ↗

{{ examples.tomorrow }}
GET /api/v2/catalog
Колледж, группы, преподаватели, аудитории и известные даты архива.
GET /api/v2/resolve
{{ examples.resolve }}
entity_type и query. Находит точные названия. Несколько совпадений — уточните выбор, не угадывайте.
GET /api/v2/schedule
{{ examples.day }}
entity_type=group|teacher|audience, entity, date либо start и end. Максимум 31 день. Даты: ГГГГ-ММ-ДД; для одного дня также today, tomorrow, yesterday. Без даты — сегодня.
GET /api/v2/coverage
{{ examples.coverage }}
Известные даты и пропуски. Название и диапазон необязательны, передавайте параметры попарно. Диапазон — максимум 366 дней.
GET /api/v2/changes
{{ examples.changes }}
entity_type, entity, date. Сохранённые редакции, добавленные и удалённые занятия. Проверяйте history_complete.
GET /api/v2/sources/{sha256}
Исходный PDF или Excel по идентификатору источника из ответа.

10 запросов в секунду на IP и маршрут; исходники — 20 в минуту. При 429 соблюдайте Retry-After. Успешные ответы кэшируются ненадолго, ошибки не кэшируются.

В адресах HTML-страниц названия с символами /, \ или начальным ~ имеют обратимо закодированный сегмент с префиксом ~. В API передавайте исходное название, например entity=С/З_4, а не этот сегмент.

Remote MCP

https://kkepik.rub1kub.ru/mcp

Streamable HTTP, только чтение расписания и источников. Подключение зависит от вашего клиента.

В браузерах с поддержкой WebMCP доступны инструменты чтения.

Статусы данных

  • available: занятия есть в опубликованном расписании.
  • no_lessons: для выбранного названия занятия не указаны в действительном источнике.
  • missing: данных на дату нет. Это не означает, что пар не было.
  • entity_not_found: название не найдено именно в источнике на этот день.
  • invalid_source: источник получен, но не обработан корректно.

«Завтра» считается по времени Краснодара: Europe/Moscow, UTC+3. Расписание в прошлом не доказывает, что занятие состоялось. Неполная история редакций не доказывает отсутствие изменений.

Цитируйте страницу дня или source.url, сохраняйте номер редакции и время получения. Если время публикации неизвестно, published_at будет null.

Личные данные

API и MCP не возвращают ДЗ, переписки, списки студентов, личные данные, оценки или посещаемость.
